# Portfolio

Vite + React 19 + Material UI.

## Run it

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Make it yours

- `src/data.js` — your name, roles, about text, skills and projects. Most edits happen here.
- `src/theme.js` — colours, fonts, corner radius.
- `src/components/Contact.jsx` — the form currently fakes sending; swap the `TODO` for a real request.
- `index.html` — page title.

## Deploy

`npm run build`, then host `dist/` on Vercel, Netlify or GitHub Pages
(for GitHub Pages set `base: '/repo-name/'` in `vite.config.js`).
